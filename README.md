# 🎵 Spotify Clone

A responsive Spotify-inspired music player built using **HTML & CSS**. This project recreates the core look and functionality of a modern music streaming interface while focusing on frontend development and user interaction.

## ✨ Features

* 🎵 Modern Spotify-inspired UI
* ▶️ Play / Pause music
* ⏭️ Next / Previous track
* 🔊 Volume control
* 🎚️ Music progress bar
* 🎧 Playlist interface
* 📱 Responsive design
* 🌙 Dark-themed interface

## 🛠️ Tech Stack

* HTML5
* CSS
